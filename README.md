# TOGO BUSINESS — plateforme de récompenses (version de démonstration)

Cette version contient l'interface complète et un prototype fonctionnel côté navigateur :
- accueil
- inscription
- connexion
- tableau de bord
- contenus rémunérés (simulation)
- portefeuille
- retrait minimum 2 000 F CFA
- Moov Money / Mixx by Yas (simulation)
- parrainage
- historique
- espace administrateur de démonstration

IMPORTANT
- Les soldes et paiements de cette version sont des données de démonstration stockées dans localStorage.
- Aucun paiement réel n'est envoyé.
- Pour la production, il faut un backend sécurisé, une base MySQL/PostgreSQL, HTTPS, authentification serveur, journalisation anti-fraude et un prestataire de paiement officiellement autorisé.
- Ne crédite pas automatiquement de l'argent réel uniquement parce qu'une vidéo est regardée : il faut une source publicitaire/commerciale réelle et des conditions de rémunération transparentes.
- Le montant d'inscription de 2 500 F et le retrait minimum de 2 000 F sont affichés comme paramètres de la plateforme ; ils ne constituent pas une garantie de revenus.
